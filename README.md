# Nexu - Aplicacion de Mensajeria en Tiempo Real

Proyecto Final del Master Frontend (DEV.F). Nexu una idea de aplicacion de mensajeria instantanea construida con **React + Vite**.

## 3. Instalacion y Ejecucion Local

```bash
# 1. Entrar al directorio del proyecto frontend
cd app-nexu

# 2. Instalar dependencias
npm install

# 3. Iniciar el servidor de desarrollo
npm run dev
```

La aplicacion se ejecutara en el entorno local (usualmente en `http://localhost:5173`).
